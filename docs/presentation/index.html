Зачем SPEC CRM

Продукт ориентирован на экспертов в своём деле: монтаж, сервис, проектные офисы, торговля — там, где нет времени разбираться в «учётных монстрах» и заполнять лишние формы.

  • Автономное управление через ИИ — создание и разбор задач из текста, голоса и документов (ТЗ, сметы, сканы).
  • Детальная интеграция — календарь, канбан, таймлайн, склад, сделки и уведомления в одном контуре.
  • Минимум трения — быстрые действия на доске, мобильный доступ, понятный интерфейс без лишних экранов.

Панель управления

Сводка активных задач, выручки и тендеров; быстрый переход к просроченным и к созданию задачи.

  • Один взгляд — и видно, что требует внимания.
  • Связь дашборда с задачами и фильтрами.

Главная панель: метрики и последние задачи

Планировщик и автоматизация

Правила по расписанию (в духе cron): повторяющиеся контрольные задачи без ручного ввода.

  • Порядок правил, включение/выключение, приоритеты и роли.
  • Запуск по требованию — «Run now» для проверки сценария.

Автономные сценарии вместо рутины

Календарь и дневной таймлайн

Колонки по исполнителям, почасовая сетка, перенос задач — наглядная загрузка дня.

  • Согласование работ в команде без отдельных таблиц.
  • Быстрое завершение и переход к карточке задачи.

Планировщик по людям и часам

ИИ-ассистент внутри CRM

Текст, голос и вложения: PDF, Word, Excel, CSV и изображения сканов — модель разбирает суть и создаёт задачи в системе.

  • Естественный язык: «создай задачу на завтра исполнителю …».
  • История диалога на сервере до выхода из сессии.

Автономное управление задачами через диалог

Месячный обзор

Календарь на месяц с индикаторами загрузки по дням; переключение «задачи / люди».

  • Удобно для обзора проектов и дедлайнов.
  • Сочетается с дневным и недельным планированием.

Месячная сетка и навигация по периодам

Мобильный доступ

  • Быстрое завершение задачи с карточки.
  • Нижняя навигация по ключевым разделам.
